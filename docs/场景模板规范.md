# 场景模板规范

新增一个学科场景 = 新建一个文件 + 在注册表里加一行。UI、数据面板、步骤条、结论卡都是通用的，**不用碰 `src/core/`**。

---

## 一、最小骨架

新建 `src/scenes/你的场景.js`：

```js
import * as THREE from 'three';
import { tween, ease, wait } from '../core/stage.js';

export default {
  id: 'lever-balance',
  name: '杠杆原理',
  icon: '⚖️',                            // 首页卡片上的图，孩子靠它认这一课
  keywords: ['杠杆', '撬棍', '省力'],     // 目前没有调用方，第二期恢复文字入口时接回来
  subject: '小学科学 / 初中物理',
  grade: '二年级 · 杠杆',                 // 首页卡片副标题；不写就退回 subject · topic
  topic: '杠杆 · 力矩平衡',

  stage: {
    cameraPos: [10, 6, 12],
    target: [0, 0.5, 0],
    withWater: false,                    // 需要水面就设 true
  },

  assets: {                              // 填入 Tripo 生成的 GLB 地址即自动替换占位模型
    weight: null,
  },

  steps: ['放置支点', '左侧加钩码', '右侧调平', '得出结论'],

  // stats 只给需要数值面板的高年级 / 演示场景用。
  // 一年级场景不要声明它 —— 孩子读不懂小数和单位，面板反而是干扰。
  stats: [
    { key: 'left',  label: '左侧力矩' },
    { key: 'right', label: '右侧力矩' },
  ],

  build(ctx) {
    const { scene, camera, renderer, controls, ui, onFrame } = ctx;

    // 1. 建模型、加进 scene
    // 2. 写物理计算
    // 3. 写交互动作

    return {
      actions: [
        { label: '① 加钩码', primary: true, run: addWeight },
        { label: '重置', ghost: true, run: reset },
      ],
      reset,
    };
  },
};
```

然后在 `src/scenes/index.js` 里注册：

```js
import lever from './lever-balance.js';
export const SCENES = [caochong, lever];
```

`npm run build` —— 完成。

## 二、`ctx` 给你什么

| | 说明 |
|---|---|
| `scene` | Three.js 场景，往里 `add()` 即可 |
| `camera` / `renderer` / `controls` | 需要射线拾取、自定义镜头时用 |
| `onFrame(fn)` | 注册每帧回调，`fn(dt, t)`：dt 毫秒增量，t 秒级时间 |
| `flyTo(pos, target, ms)` | 镜头飞到指定位置，返回 Promise。用来做「换个角度看」 |
| `ui` | 界面控制，见下 |

`ctx.ui` 是包过一层的：这一课被换掉之后，它残留的 `await` 链会自动停在原地，
不会把上一课的语音和提示盖到下一课上。所以场景里不用自己判断「我还活着吗」。

## 三、`ui` 能调什么

### 面向孩子的（一年级场景主要用这些）

```js
// 显示一句大字并念出来，返回念完的 Promise
await ui.say('点一点每个图形，听听它们叫什么名字');
await ui.say('这是圆柱', { hold: 2000 });        // hold：多少毫秒后自动收起
ui.say(HINT, { mute: true });                   // mute：只显示不朗读

// 先猜再看 —— 这是整套 API 里最重要的一个
const a = await ui.ask('圆柱从上面往下看，是什么形状？', [
  { label: '圆形', icon: '⚪' },
  { label: '正方形', icon: '🟦' },
  { label: '三角形', icon: '🔺' },
]);
// a = { index, label }

// 揭晓。猜错不打叉、不扣分，只说「再看看」
await ui.judge(a.index === 0, '从上面看，圆柱是一个圆');

// 图形化计数，代替数字面板
ui.tally([
  { label: '能滚',   count: 2, icon: '⚪' },
  { label: '不能滚', count: 2, icon: '⬛' },
]);

ui.setStep(2);                                   // 当前第几步（从 0 开始）

const again = ui.showResult({
  icon: '🎉',                                    // 有 icon 就用大图，没有就显示"实验结论"
  title: '圆圆的能滚，方方的站得稳',
  note: '球和圆柱有圆圆的面，所以能滚……',          // 支持 HTML
  grown: '这一课的落点是"按特征分类"。可以追问……',  // 给陪读的大人看的一行小字
});
again.onclick = () => { ui.hideResult(); reset(); };   // showResult 返回「再玩一次」按钮
```

`showResult` 自带「再玩一次 / 换一个」两个按钮，「换一个」会自动回首页，不用自己接。

### 面向老师 / 高年级的（声明了 `stats` 才会出现）

```js
ui.setStat('left', '120 N·m', true)     // 第三个参数 true = 高亮成绿色
ui.setProgress(78, false)               // 进度条百分比 / 是否完成态
ui.setHint('还差 3.2 cm', false)
ui.toast('已在船舷刻下吃水线')            // 底部浮层，2.6 秒自动消失
ui.showResult({ title, big, unit, equation, note })
```

## 四、动画助手

```js
import { tween, ease, wait, loadGLB } from '../core/stage.js';

// 1800ms 内把 k 从 0 补到 1，每帧回调
await tween(1800, k => {
  const e = ease(k);                     // 缓入缓出
  obj.position.x = from + (to - from) * e;
});

await wait(500);                         // 等待

const model = await loadGLB(url, { length: 3.4, THREE });  // 自动归一化尺寸 + 落地对齐
```

## 五、必须遵守的规矩

### 1. 物理要真算

```js
// ✅ 对：从公式推
const draft = mass / (RHO * AREA);

// ❌ 错：写死关键帧
const draft = step === 3 ? 0.5 : 0.1;
```

老师会追问原理，学生会改参数试。算错的课件比没有课件更糟。

### 2. 随机必须确定

```js
let _s = 20260826;
const rnd = () => ((_s = (_s * 1664525 + 1013904223) % 4294967296) / 4294967296);
```

**不要用 `Math.random()`。** 每次打开画面必须完全一致，否则老师排练好的那一版和课堂上放的那一版长得不一样。

### 3. 连点不能丢

老师在讲台上会快速连点。动作要排队，不能因为 `busy` 就直接丢弃：

```js
let queue = Promise.resolve();
const enqueue = item => {
  if (item.userData.queued) return;
  item.userData.queued = true;
  queue = queue.then(() => doAction(item)).catch(() => {});
};
```

### 4. 每节课至少有一个预测点

没有 `ui.ask()` 的课件，学生全程只是在看动画。`npm run check` 会直接报错拦下来。

预测点要放在**结果揭晓之前**：先让孩子承诺一个答案，再给他看真相。这个先后顺序是这个产品和「播动画」的分界线。

### 5. 不要保证必然成功

试错类的实验（配平、称量、代换），必须存在「做不对」的状态，并且孩子能看见、能改。

```js
// ❌ 错：把重量凑成刚好相等，孩子点够次数就一定成功
const k = TARGET / raw.reduce((a, b) => a + b, 0);

// ✅ 对：允许加多，加多了天平往另一边倒，提示"加多啦"
if (dm < 0) await ui.say('加多啦，天平往方块那边倒了');
```

必然成功的流程等于把思维过程删掉了，剩下一段好看的动画。

### 6. 节奏不能挂在朗读上

家长会关掉朗读，有些浏览器根本没有 TTS。`speak.js` 在这两种情况下仍按字数留出停顿——
所以**用 `await ui.say(...)` 来控制节奏是安全的**，不要自己写死 `wait(2000)` 去配语音长度。

## 六、数值怎么定

先定「看得见的效果」，再倒推参数。

以曹冲称象为例：希望空载吃水 0.10 m、载象吃水 0.50 m，视觉上下沉 40 cm 明显但不沉船（船舷 0.90 m）。于是：

```
船底面积 A = 5.0 × 2.2 = 11 m²
船自重 1100 kg  → 1100 / 11000 = 0.10 m  ✓
大象 4400 kg    → 5500 / 11000 = 0.50 m  ✓
```

数字都是整的，板书起来也好看。**先设计观感，再配参数，不要反过来。**

## 七、自检清单

先跑 `npm run check`（结构和学科不变量是机器判的），再人工过一遍下面这些：

- [ ] 关掉网络能正常打开
- [ ] 连点每个按钮 10 次不卡死、不错乱
- [ ] 「重置」后状态完全干净，能重跑第二遍
- [ ] 手机竖屏下按钮不重叠、能操作
- [ ] 结论数字和物理公式对得上
- [ ] 刷新两次，画面完全一致
- [ ] 关掉右上角朗读，整条流程节奏仍然正常（不会一路飞过去）
- [ ] 中途点左上角「←」换一课，上一课的语音和提示不会漏到下一课
