# 接入 AI 生成链路（即梦 → Tripo → GLB）

当前 V0.1 用的是**内置程序化占位模型**。本文说明怎么换成真实 AI 生成的模型。

---

## 一、最快的一步：手动跑一次，填地址

不用写任何代码就能看到效果。

1. 在[即梦 / 火山方舟](https://www.volcengine.com/)生成参考图
   提示词模板：`一头亚洲象，全身侧面，站立，纯白背景，无阴影，产品图，正交视角`
   > **关键**：纯白背景 + 单一物体 + 无阴影，Tripo 的转换质量高很多。

2. 把图丢进 [Tripo](https://www.tripo3d.ai/) 的 Image to 3D，下载 GLB

3. 放进 `assets/models/elephant.glb`

4. 打开 `src/scenes/caochong-chengxiang.js`，改这一行：

```js
assets: {
  elephant: './assets/models/elephant.glb',   // ← 填上
  boat: null,
  stone: null,
},
```

5. `npm run build`

模型会自动归一化尺寸（长边对齐到 3.4 m）并落地对齐，不用手调。加载失败会自动回退到内置模型，不会白屏。

> 注意：填了本地路径后就不再是单文件了，需要把 `assets/` 一起分发。要保持单文件，把 GLB 转成 base64 data URI 内联。

---

## 二、自动化：接 API

### 1. 即梦 Seedream（火山方舟）

- 计费：约 $0.03 / 张（Seedream 4.0）
- 响应：8–20 秒
- 固定风格：把 Prompt 模板 + 风格参考图写死，保证同一节课的素材风格统一

### 2. Tripo OpenAPI

- 异步任务制：提交 → 轮询 `task_id` → 拿 GLB 下载地址
- 计费：1 credit = $0.01
  | 操作 | credits |
  |---|---|
  | 图生 3D（含标准贴图） | 30 |
  | 智能重拓扑 | 30 |
  | 自动绑骨 | 25 |
  | 动画重定向 | 10 |
- 响应：60–180 秒（**这是整条链路的瓶颈**）

### 3. 建议的服务端流程

```
POST /api/generate  { sceneId, object }
  ↓ 查缓存（命中直接返回 GLB 地址，秒级）
  ↓ 未命中：即梦生图（3 张备选，取第 1 张）
  ↓ Tripo 提交图生 3D 任务
  ↓ 轮询任务状态
  ↓ 下载 GLB → 归一化（尺寸 / 朝向 / 中心点）→ 存对象存储
  ↓ 写入缓存
返回 { url, cached: false, elapsed: 142s }
```

**必须做缓存。** 没有缓存，同一头大象每次都要等 3 分钟、每次都花 3 块钱。

## 三、成本参考（2026-08 查证）

| 项目 | 成本 |
|---|---|
| 单次生成（1 图 + 图生 3D） | 约 2.4 元 |
| 单次生成（3 图选 1 + 图生 3D） | 约 2.8 元 |
| 单个**可用**素材（含 2–3 轮重试） | 约 7 元 |
| 带绑骨动画的完整档 | 约 19 元 |
| 200 个知识点建库 | 约 1,400 元 |

美元按 1 : 7.15 折算。

> **结论：API 便宜到可以忽略，真正的成本是人工精修和场景模板开发。** 不要为了省 API 费用去做复杂的优化，把时间花在场景质量上。

## 四、单图转 3D 的三个坑

| 坑 | 表现 | 处理 |
|---|---|---|
| **朝向不确定** | 模型可能朝任意方向 | 入库时统一归一化，必要时人工标一次朝向 |
| **比例不标准** | 大象和船不成比例 | 按现实尺寸缩放（`loadGLB` 的 `length` 参数） |
| **没有骨骼** | 模型不能走、不能动 | 需要动画就加 Tripo 自动绑骨（+25 credits），或用位移动画替代 |

还有一条最重要的：**单图转 3D 给的是「道具」，不是「实验」。** 大象模型再逼真，浮力逻辑还是得自己写。这就是为什么这个项目的核心资产是场景模板，不是 AI 链路。
