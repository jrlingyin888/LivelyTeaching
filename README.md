不是播动画，不是看视频——孩子可以拖、可以点、可以猜错重来，**物理是真算的**。

当前版本面向**一年级**：不识几个字也能自己玩完一课。所有关键提示都会念出来，界面上没有小数、没有单位、没有看不懂的仪表盘。

构建产物是**一个 HTML 文件**：双击就能开，不联网、不装环境。

## 快速开始

```bash
npm install
npm run build      # 产出 dist/index.html（单文件）
npm run dev        # 开发模式，自动重建
npm run serve      # 本地起服务预览
npm run check      # 课件自检（见下）
```

打开 `dist/index.html` → 点一张图 → 开始。

## 已实现的三课

### 1. 认识立体图形 · 一年级数学

长方体 / 正方体 / 圆柱 / 球。五步：认一认 → 看一看 → 滚一滚 → 堆一堆 → 分一分。

3D 在这里有不可替代的价值：一年级最难的一点是**同一个物体从不同角度看形状不一样**。「圆柱从上面看是什么形状？」——先让孩子猜，再把镜头飞到正上方揭晓。

滚坡是真算的：

```
a = g·sinθ / (1 + I/mr²)      球 2/5 · 圆柱 1/2 · 方块不滚
```

球和圆柱的快慢只差 3%，肉眼看不出，所以教学落点放在「能滚 / 不能滚」，**不拿看不见的差别当结论**。

### 2. 谁轻谁重 · 一年级科学

天平。四步：猜一猜 → 大的一定重吗 → 用方块量 → 排一排。

第二步是专门用来撞前概念的：**大气球 vs 小石头**，多数孩子会猜大的重。天平给出相反的答案。

倾角按真实等臂天平的平衡方程算：

```
tanθ = (mL − mR)·L / (M·d)
```

第三步让孩子一块一块加小方块，加多了天平会往另一边倒——**试错过程是保留的**。

### 3. 曹冲称象 · 演示用

面向老师演示和高年级，保留了数值面板。浮力真算：`d = m / (ρ·A)`。

## 面向一年级做了什么

| | |
|---|---|
| **朗读** | 关键提示一律念出来（`speechSynthesis`，全平台）。孩子不识字，但听得懂 |
| **不用数字讲事实** | 天平就是倾角，滚坡就是谁先到底，数量用一排图形表示 |
| **一次最多 3 个大按钮** | 该点哪个就亮哪个 |
| **猜错不惩罚** | 只说「再看看」，不打叉。一年级一旦有挫败感就不肯玩了 |
| **节奏不依赖朗读** | 家长关掉朗读、或浏览器没有 TTS 时，仍按字数留出停顿 |

## 课件自检

`npm run check` 跑的是**不需要人看就能判定对错**的规则。每一条都来自一次真实的返工：

- 每节课至少要有一个「先猜再看」的预测点，否则学生只是在看动画
- 每节课必须走得到结论
- 天平的物体质量必须是方块单位的整数倍，否则会量出「五块多一点」
- 关键词不能撞车（撞了会静默匹配错场景）
- 首页卡片需要的字段一个都不能少

人工发现一次，就沉淀成这里的一条，之后不用再靠眼睛盯。

## 目录结构

```
src/
  core/
    stage.js        Three.js 舞台：渲染、光照、镜头飞行、dispose、GLB 加载
    ui.js           界面层：朗读大字、预测卡、揭晓、图形化计数、结论卡、首页
    speak.js        语音朗读
  scenes/
    index.js        场景注册表（顺序就是首页卡片顺序）
    solid-shapes.js         认识立体图形
    balance-scale.js        谁轻谁重
    caochong-chengxiang.js  曹冲称象
  main.js           入口：首页 → 装配舞台 → 可随时换一课
  shell.html        HTML 外壳（构建时把 JS 内联进来）
check.mjs           课件自检
build.mjs           单文件构建
```

## 路线图

**第一期（当前）** 自用版。给自家一年级孩子用，看效果，再给几位朋友试。

**下一期** 取决于第一期的真实反馈。可能的方向：

- 按一年级课标补齐更多知识点
- 把两个场景重复的教学编排抽成声明式描述（写完第二个场景之后再抽，不预先设计）
- 更远：AI 生成课件 + 多模型质检流水线，让课件不再靠手写
